## 🛠️ Tecnologías y Herramientas

- **HTML5 Semántico**: Estructura accesible (`header`, `nav`, `section`, `footer`) optimizada para SEO y lectores de pantalla.
- **CSS3 Moderno**:
  - Variables CSS (`:root`) para consistencia en la paleta de colores (modo oscuro cyberpunk / dark tech).
  - *CSS Nesting* nativo para código modular y mantenible.
  - *CSS Grid* y *Flexbox* para maquetación avanzada.
  - Diseño 100% responsivo adaptado a móviles, tablets y monitores de escritorio.
- **JavaScript (ES6+)**: Interactividad y validación.
- **Git & GitHub**: Control de versiones y despliegue continuo.

## 📁 Secciones del Portafolio

1. **Hero / Presentación**:
   - Saludo e introducción profesional.
   - Enlaces directos a perfiles de GitHub, LinkedIn y descarga de Curriculum Vitae (CV en PDF).
2. **Sobre Mí**:
   - Resumen de perfil, objetivos profesionales, mentalidad de trabajo y misión personal.
3. **Habilidades (Skills)**:
   - Tecnologías y herramientas dominadas: HTML5, CSS3, JavaScript, React, React Router, Axios, Tailwind CSS, Bootstrap, Node.js, Supabase y SQL.
4. **Proyectos Destacados**:
   - **Menú Digital Fullstack**: Aplicación web moderna para restaurantes con Astro, TypeScript, Tailwind CSS, Turso (LibSQL), Cloudinary y pruebas con Vitest.
   - **SteamNoThanks**: Comparador de precios de videojuegos entre tiendas oficiales (IsThereAnyDeal API) y tiendas de claves en tiempo real (Web Scraping).
   - **TOTP 2FA Authenticator**: Aplicación de escritorio para Windows (Python + CustomTkinter) con bóveda cifrada AES-256 y escáner de códigos QR.
   - **Wroutine**: Aplicación web desplegada en Vercel para seguimiento de rutinas de ejercicio e intervalos de descanso.
   - **Control Stock**: Sistema de gestión de inventario y stock con React, operaciones CRUD completas y base de datos (Supabase / PocketBase).
5. **Certificaciones y Formación**:
   - **Ingeniería en Desarrollo de Aplicaciones** - Universidad de San Pedro Sula (USAP) (2021 - Presente).
   - **Formaciones y Cursos de Especialización** - Oracle Next Education (ONE) / Alura Latam y Udemy.

## 💻 Instalación y Uso Local

Si deseas clonar y explorar este proyecto en tu entorno local:

1. Clona el repositorio:
   ```bash
   git clone https://github.com/LuisCFunes/portfolio.git
   ```
2. Accede al directorio:
   ```bash
   cd portfolio
   ```
3. Abre el archivo `index.html` en tu navegador preferido o utiliza una extensión como *Live Server* en VS Code.
